# Тестирование расширенного приложения

## 🚀 Быстрый старт

1. **Запустить сервер** (если еще не запущен):
   ```bash
   cd Gitea/frontend-framework/example/public
   python3 -m http.server 8000
   ```

2. **Открыть в браузере**:
   http://localhost:8000

3. **Использовать инкогнито** для избежания кэширования

## 📝 Если что-то не работает

1. **Hard refresh**: Ctrl+Shift+R (или Cmd+Shift+R на Mac)
2. **Открыть инкогнито**: Избежать кэширования
3. **Проверить консоль**: F12 → Console tab
4. **Проверить Network**: F12 → Network tab (для HTTP запросов)
5. **Проверить сервер**: Должен быть запущен на порту 8000
